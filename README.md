## Building

```bash
go build
```

## Usage

```bash
./chat-editor -h
Usage of ./chat-editor:
  -db string
        Database name (default "dieter")
  -host string
        Database host (default "localhost")
  -id string
        Chat ID to load
  -pass string
        Database password
  -port string
        Database port (default "5432")
  -user string
        Database username (default "prisma")
```
